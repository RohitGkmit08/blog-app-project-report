# 2. Scope & Objectives

## 2.1 Purpose
The purpose of this project is to design and develop a **Blog Management Application** that enables administrators to create and manage blog content while allowing users to read, comment, and subscribe for updates.  
The system aims to deliver a lightweight, user-friendly alternative to heavy CMS platforms, focusing on simplicity, engagement, and control.

---

## 2.2 Scope

**A. User-Facing Features**
- View published blogs with category-based filtering.  
- View blog details, author information, and publish date.  
- Add comments on blogs (pending admin approval).  
- Subscribe to the newsletter using an email address.  

**B. Admin-Facing Features**
- Secure login and authentication system for administrators.  
- Create, edit, publish, unpublish, and delete blogs.  
- Moderate user comments (approve/reject).  
- Manage newsletter subscribers.  
- Send newsletters to subscribers directly from the dashboard.  
- Access dashboard analytics showing blog count, drafts, comments, and subscribers.

---

## 2.3 Objectives

The key objectives of this project are as follows:

| Objective | Description | Success Indicator |
|------------|--------------|-------------------|
| **Simplify Blog Management** | Provide a clean admin dashboard for creating and managing blogs. | Admin can publish or edit blogs with ease. |
| **Enhance Reader Engagement** | Enable users to comment and interact with blog content. | Increase in approved comments and engagement metrics. |
| **Ensure Content Quality** | Implement moderation for all comments before publishing. | zero unapproved or spam comments visible publicly. |
| **Centralized Control** | Allow the admin to manage content, comments, and newsletters in one place. | Single dashboard managing all core operations. |
