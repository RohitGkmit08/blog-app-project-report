# 4. Assumptions, Constraints, and Dependencies

## Assumptions
- Users will have stable internet access.
- Subscribers provide valid email addresses.
- Admin users are verified and registered.

## Constraints
- Only approved comments will be displayed publicly.
- Newsletter frequency will be regulated to prevent spam.
- Email delivery relies on external email service availability.

## Dependencies

- **MongoDB (Database Storage):**  
  Used to store all blog content, user comments, newsletter subscribers, and admin credentials securely.  


- **NodeMailer (Email Delivery):**  
  Required for sending newsletters and notifications to subscribed users.

- **Cloud Hosting Environment:**  
  Ensures uptime and public accessibility for both the frontend and backend services.
