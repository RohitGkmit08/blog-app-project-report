# 7. Data & Information Requirements

## Key Data Entities
| Entity | Description |
|---------|-------------|
| Blog | Contains blog details, category, and author. |
| Comment | Stores comments linked to a specific blog. |
| Subscriber | Stores email addresses for newsletters. |
| User | Represents admin and users. |

## Data Lifecycle
- **Create:** Admin adds blogs, users comment, subscribers join.
- **Modify:** Admin updates blogs.
- **Delete:** Admin removes blogs or comments.
- **Archive:** Comments remain in the database for record-keeping.
